# Central States / Ascent Standing Seam Clips

Calibrated from Ascent technical manuals (Central Seam Plus, Central-Loc, Central Span).

## Central Seam Plus (mechanical)

| Part | Description |
|------|-------------|
| CL2122 | 2\" Sliding Clip Low |
| CL2124 | 2\" Sliding Clip High |
| CL7760 | 24\" Back-up Plate |
| CL7769 | 18\" Back-up Plate |
| CL7600 / CL7616 | Eave Plate Low / High (8') |
| CL7710 / CL7720 | Rake Support Low / High (20') |
| CL7500 | Bearing Plate (rigid board) |

**Fasteners:** 2 per clip — FSS1 (purlins) or FT1 (joists). Clips at each purlin; module control at endlap.

## Central-Loc (snap)

| CL200 / CL204 | Fixed Low / High |

## Thermal spacer

Required for **HIGH** clip systems over insulation (manual Step 3). Shipper may show CL575 / thermal block.

## Shipper aliases still recognized

CSP212, CS2124, FSS10 — seen on Complete Shippers; mapped to generic sliding entry.

# Branding — Ascent Shipper Checker

## Software identity

| | |
|--|--|
| Official name | **Ascent Shipper Checker** |
| Code name | Chubby Checker |
| Logo | Ascent Buildings mark (black triangle + red swoosh) |

## Icon guidance

1. Use the official Ascent Buildings logo as the software mark.
2. Preferred transparent PNG master: `assets/branding/ascent_logo.png`
3. App icon sizes: 16, 32, 48, 64, 128, 256, 512 px
4. Windows Desktop shortcut: `ascent_chubby.ico` (label: **Ascent Chubby**)
5. Always show software name near the logo in UI/docs: **Ascent Shipper Checker**

## Do I need to load the logo into GitHub?

**Yes**, if you want:
- The logo on the GitHub README
- PDF reports to include the logo automatically
- Installers / shortcuts to ship with the official icon

Binary image files must be committed to the repo (or attached to releases). The text scaffolding under `assets/branding/` is already in GitHub; upload the image files into that folder.

Step-by-step is in `assets/branding/README.md`.
